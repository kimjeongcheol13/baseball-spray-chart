개인정보처리방침

SprayLab (kimjeongcheol13.github.io/baseball-spray-chart) · 시행일 2026-09-30

SprayLab은 아마추어 야구 타구 기록·분석 웹앱입니다. 로그인 없이 쓸 수 있고, 모든 기록은 사용자의 기기(브라우저)에 저장됩니다. 로그인, 팀 코드, 경기 공유 링크, 의견 보내기를 사용할 때만 해당 내용이 서버로 전송됩니다. 이 문서는 선택 기능을 쓸 때 어떤 정보가 어디로 가는지 설명합니다.

2. 제3자 제공 및 처리 위탁

수집한 정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 서비스 운영을 위해 아래 서비스를 이용합니다.

  • Supabase — 로그인·동기화·의견 데이터 저장
  • Google — 구글 로그인, Google Analytics 방문 통계
  • Formspree — 의견 보내기 전달
  • Kakao — 사용자가 카카오톡 공유를 누를 때 공유 기능 제공
  • GitHub Pages — 웹사이트 호스팅

3. 보관 기간과 삭제

  • 기기에 저장된 기록: 앱의 데이터 관리 메뉴나 브라우저 데이터 삭제로 언제든 지울 수 있습니다.
  • 클라우드에 저장된 계정·기록: 계정 삭제를 요청하면 지체 없이 삭제합니다. 요청이 없으면 서비스 제공 기간 동안 보관합니다.
  • 방문 통계: Google Analytics 기본 보관 기간을 따릅니다.

4. 이용자의 권리

이용자는 언제든 자신의 정보 열람·수정·삭제·처리 정지를 요청할 수 있습니다. 구글 계정의 타사 앱 액세스에서 SprayLab 연결을 직접 해제할 수도 있습니다.

5. 아동의 개인정보

유소년 선수의 기록은 코치·보호자가 입력하는 경기 기록이며, SprayLab은 만 14세 미만 아동에게 직접 계정 생성을 요구하지 않습니다. 선수 이름 대신 별칭·등번호 사용을 권장합니다.
