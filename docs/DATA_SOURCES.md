# 데이터 출처 (DATA_SOURCES)

작성일: 2026-10-12

## 1. 데모 데이터

고정 시드로 생성한 가상 팀·선수다. **실존 인물·실제 기록이 아니다.**

| 위치 | 내용 |
|---|---|
| `js/sample.js` — "샘플 데이터로 둘러보기" | 고정 시드(`SEED = 20268256`)로 생성한 가상 팀 '샘플팀' 타자 9명 × 3경기 (상대 '한빛팀' · '동산팀' · '미래팀'). 경기 날짜는 샘플을 연 날 기준 15 · 8 · 2일 전. 사용자 기록과 섞이지 않게 샘플 칸(`sl_sample__*`)에만 저장한다. |
| `js/features/report.js` — "샘플 선수 리포트 보기" | 코드에 고정값으로 적은 가상 선수 '김하늘' 1명 · 6경기 28타석. 메모리에서만 쓰고 저장하지 않는다. |

## 2. 실제 팀 데이터

사용자가 직접 입력하며 사용자 기기(LocalStorage)에 보관한다. 클라우드 동기화는 로그인 시 선택이다.

## 3. 공개 데이터셋 검토 기록

데모 데이터를 공개 데이터셋으로 바꿀 수 있는지 검토했고, 아래 이유로 채택하지 않았다.

| 데이터셋 | 검토 결과 | 결정 |
|---|---|---|
| MLB Statcast (Baseball Savant) | MLBAM 저작권 고지(http://gdx.mlb.com/components/copyright.txt) 기준 개인·비상업 이용만 허용 | 미채택 |
| KBO | 공개된 타구 좌표 데이터 없음 | 미채택 |
